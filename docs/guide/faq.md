# 常见问题与排查

## 🔹 连接超时或一直停在“正在连接”

按顺序检查：

1. 服务器地址必须包含端口：`laoke.vincentzyu233.cn:61027`；
2. 客户端必须是 Minecraft `26.3`；
3. Fabric Loader 必须为 `0.20.1`；
4. 启动日志没有缺少 Fabric API 或其他模组的错误；
5. 先尝试直连，不要同时开启多个加速器或代理；
6. 服务器正在重启时等待一到两分钟再重试。

如果其他玩家能进入而你不能，请带上客户端日志中的报错内容联系管理员。

## 🔹 Java 版本错误

Minecraft 26.3 与当前服务端模组使用 **Java 25**。

在 PCL CE 中：

1. 打开版本设置；
2. 找到 Java 选择；
3. 选择 JDK 25 的 `java.exe`；
4. 重新启动游戏。

不要使用 Java 8、17 或 21 启动这个版本。

## 🔹 提示先登录或注册

这是 EasyAuth 的账号保护。

第一次进入：

```text
/register <密码> <再次输入密码>
```

以后进入：

```text
/login <密码>
```

忘记密码时联系管理员重置，不要重复注册新 ID。

## 🔹 为什么我不能破坏方块

普通玩家默认是“创造模式参观”，负责防破坏的 `visitor_guard` 会拒绝：

- 破坏与放置；
- 方块交互；
- 攻击与 PvP；
- TNT、火焰、流体更新；
- 物品掉落与拾取。

该限制不代表客户端故障。需要参与建设时请阅读[建筑权限与协作规范](/guide/builder)。

## 🔹 Axiom 能打开但不能编辑

Axiom 的权限只授予 `builder` 角色。若你只是访客，Axiom 可以用于查看，但服务端会拒绝修改请求。

获得建筑师权限后，退出并重新进入服务器，再检查角色是否生效。

## 🔹 WorldEdit 命令不生效

WorldEdit 是服务端命令：

- 输入时注意使用双斜杠，例如 `//pos1`；
- 木斧选区没有客户端线框属于正常现象；
- 确认你已经拥有 `builder` 角色；
- 大范围命令可能因方块数量过多或区块未加载而失败；
- 失败后先用 `//undo`，不要连续重复执行。

## 🔹 皮肤不显示

先执行：

```text
/skin refresh
```

仍不生效时：

1. 检查 Mojang 或 Ely.by 是否有可用皮肤；
2. 尝试 `/skin set mojang` 或 `/skin set ely.by`；
3. 退出服务器后重新进入；
4. 确认没有其他皮肤模组覆盖服务器同步结果。

## 🔹 小地图与光影

- Xaero 小地图：按 `M`；
- Zoomify：按 `C` 放大；
- Iris 光影菜单：按 `K`；
- 光影包已预置 Complementary Reimagined 和 BSL。

如果打开光影后帧率明显下降，先降低渲染距离、阴影质量和云层效果。

## 🔹 客户端应该分配多少内存

建议：

| 场景 | 内存 |
| --- | --- |
| 仅建筑和参观 | 4 GB |
| 光影 + 小地图 + Axiom | 6 GB |
| 超远渲染距离/高清材质 | 8 GB 以上 |

客户端内存不应大于系统物理内存的一半。

## 🔹 服务器会保存我的地图缓存吗

不会。服务器不会读取客户端 Xaero 地图缓存。公开 MRPack 也已移除作者本机的多人地图缓存，避免把旧地形带到你的客户端。
