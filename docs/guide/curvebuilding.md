# 曲线道路与基建放样指南 (CurveBuilding)

本指南说明如何在服务器中使用 **CurveBuilding** 模组，配合 WorldEdit 将预设的道路断面沿**贝塞尔样条曲线（Bézier Curve）**无缝拉伸，高效铺设校园弯道、环岛、跨海大桥与弧形建筑。

::: tip 核心价值
告别传统铺路生硬的阶梯锯齿与纯单一方块线！CurveBuilding 允许你先设计好一段带**路面标线、人行道地砖、台阶路沿石**的完整横截面，然后像 3D 建模中的“放样拉伸（Loft / Sweep）”一样，让整条复杂大马路顺着优雅的曲线自然平滑延伸。
:::

---

## 🔹 适用场景与运行环境

* **适用工程**：
  * 集美学村校园沥青主干道与弯曲林荫小道；
  * 环岛与弧形转盘；
  * 跨海引桥、高架桥与倾斜坡道；
  * 体育场圆形跑道与弧形看台轮廓。
* **环境状态**：
  * **服务端**：已正式部署 `curvebuilding-fabric` 运行于 iMac 2015（Minecraft 26.3 / Fabric）；
  * **客户端**：**无需额外安装模组**（纯服务端发包，粒子与方块更新全原生兼容）；
  * **权限要求**：拥有 `builder` 或 `op` 权限即可直接使用。

## 🔹 核心工作流（四步铺出一条弯道）

```mermaid
flowchart LR
    A["① 制作断面切片<br>(带沥青/标线/路沿石)"] --> B["② WE 复制到剪贴板<br>(//copy)"]
    B --> C["③ 标记贝塞尔控制点<br>(//bcpos set 1 / 2)"]
    C --> D["④ 全息粒子核验<br>(观察曲线走向)"]
    D --> E["⑤ 一键放样铺设<br>(//bc)"]
```

### 第一步：在平地上建造 1 格长的“标准道路切片”

不要在弯道上直接建！先在附近开阔空地上，造出一段厚度仅为 **1 个方块** 的道路横截面切片：

* **典型校园马路切片参考**：
  * 中间：黑色/灰色混凝土（沥青车行道，宽 6 格）；
  * 车道中缝：黄色混凝土（道路中央虚线/双实线）；
  * 两侧：平滑石台阶（路沿石）；
  * 外侧：安山岩/深板岩砖（人行道，宽 2 格）。
* **复制进剪贴板**：
  1. 拿小木斧分别左键、右键圈中这个切片；
  2. 站在切片一侧地面的边缘（作为后续贴合的基准锚点）；
  3. 执行：
     ```text
     //copy
     ```

---

### 第二步：标记弯道贝塞尔曲线控制点（`//bcpos`）

人物移动到实际需要铺路的弯道区域，用坐标指令设定贝塞尔曲线：

1. **设定起点**：走到弯道起点，输入：
   ```text
   //bcpos set 1
   ```
2. **设定终点**：走到弯道终点，输入：
   ```text
   //bcpos set 2
   ```
3. **精细调节弯曲弧度（手柄控制点）**：
   * 贝塞尔曲线需要控制杆来决定曲线的凸出程度和倾斜切线；
   * 走到你希望弯道向外鼓起的切线延伸位置，输入：
     ```text
     //bcpos set 1f
     ```
     *(💡 `1f` 表示起点向前延伸的控制点，`2b` 表示终点向后收束的控制点)*。

> [!TIP] 观察实时粒子光线
> 设置好控制点后，世界中会立刻显示出发光的**全息彩色粒子线**！  
> 你可以退后飞行观察，粒子线完全真实反映了马路最终的走向与弧度。如果不满意，随时重设点位。

---

### 第三步：一键沿曲线放样铺设（`//bc`）

确认全息粒子走向完全符合预期后，执行放样命令：

```text
//bc
```

**奇迹显现**：服务器会在一秒内将你的整套道路截面顺着贝塞尔曲线扭转、插值并严密铺设出来，每一格方块都完美贴合弧度！

* **常用参数选项**：
  * **仅替换空气（防挖坑）**：
    ```text
    //bc -a
    ```
    只在空气方块处生成道路，保留原有的路灯、山体或地下建筑。
  * **切片轴向对齐**：
    如果复制切片时方向不一致，可用 `-x` 或 `-z` 参数指定截面切线：
    ```text
    //bc -x
    //bc -z
    ```

---

### 第四步：撤销与连续铺设

* **撤销错误操作**：
  如果放样效果与预期有偏差，直接输入：
  ```text
  //undo
  ```
  即可一键撤销并清空现场，调整 `//bcpos` 点位后重新执行 `//bc`。
* **清空控制点**：
  施工完毕或准备画下一条新路时，清空当前粒子点：
  ```text
  //bcpos clearall
  ```

## 🔹 CurveBuilding 常用指令速查

| 指令 | 说明 | 示例 / 参数 |
| :--- | :--- | :--- |
| `//bc` | 执行曲线放样拉伸 | `//bc` 或 `//bc -a`（忽略空气） |
| `//bcpos set <点号>` | 在当前脚下设置控制点 | `//bcpos set 1` / `//bcpos set 2` |
| `//bcpos set <点号>f` | 设置该点的前向延伸切线手柄 | `//bcpos set 1f`（控制弯道出角弧度） |
| `//bcpos set <点号>b` | 设置该点的后向收束切线手柄 | `//bcpos set 2b`（控制弯道入角弧度） |
| `//bcpos insert <点号>` | 在已有两点之间插入新节点 | 适合铺设 S 型连续多段弯道公路 |
| `//bcpos remove <点号>` | 移除指定编号的控制点 | `//bcpos remove 2` |
| `//bcpos clearall` | 清空所有当前曲线控制点 | 结束当前道路施工时使用 |
| `//undo` | 撤销上一次放样铺设 | WorldEdit 标准撤回，完全支持 |

## 🔹 施工规范与避坑原则

1. **严禁破坏 Y=5 像素地图**：
   * 校园道路通常铺设在 `Y=6` 及以上高度；
   * 在低矮路段施工前，确认路基下方不会贯穿到 `Y=5` 的高德地图地毯层。
2. **长距离公路分段放样**：
   * 贝塞尔曲线非常适合几十格到两百格以内的自然弯道；
   * 对于长达数百米的环校公路，建议拆解为 **3~4 个平滑小弧段** 分别铺设，既方便微调坡度，又能防止一次性计算量过大。
3. **施工完毕随手清理**：
   * 放样完成后随手敲一下 `//bcpos clearall` 与 `//desel`，保持视口干净清爽。
