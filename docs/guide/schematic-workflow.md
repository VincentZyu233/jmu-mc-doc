# 投影预览与 WorldEdit 放置

本页说明如何用 Axiom 预览 Sponge Schematic 投影，再通过服务端 WorldEdit 完成试放、正式放置和撤回。

::: tip 推荐顺序
**Axiom 导入预览 → 管理员上传同一份文件 → WorldEdit 加载 → 无方块试放 → 正式粘贴 → 必要时撤回**
:::

## 🔹 适用范围与前置条件

本流程适用于 Sponge Schematic v3 格式的 `.schem` 文件，例如 `jmusouthgate.schem` 和 `jmubuilding.schem`。

开始前确认：

- 已获得 `builder` 或 `op` 权限；
- 客户端使用服务器整合包，Axiom 和 WorldEditCUI 正常加载；
- 目标区域的区块已经加载；
- 大体量施工已通知管理员，并确认存在近期备份。

Axiom 只用于客户端里的位置和朝向预览。真正修改服务器世界时，本流程使用 WorldEdit。

::: warning 客户端和服务端需要同一份文件
Axiom 导入的是你电脑上的 `.schem`，WorldEdit 读取的是服务器 schematic 库里的文件。请把同一份文件交给管理员上传，避免尺寸或版本不一致。
:::

## 🔹 第一步：在 Axiom 中导入并预览

1. 进入服务器并打开 Axiom 编辑器。
2. 在菜单中选择 `File → Import Schematic...`。
3. 选择本地 `.schem` 文件完成导入。
4. 打开 `Blueprint Browser`，确认投影已经出现。
5. 选中投影后按 `Ctrl+V`，进入放置预览。
6. 通过 `Placement Options`、旋转和翻转，把投影移动到目标位置。

重点检查：

- 建筑朝向与道路、地形是否一致；
- 投影底部是否位于 `Y=6` 或更高；
- 建筑是否避开 `Y=5` 的卫星像素地图；
- 是否需要旋转 90、180 或 270 度；
- 建筑占地是否与相邻区域冲突。

记录最终站位、朝向、旋转角度和大致范围。预览完成后取消或退出放置，不要在本流程中直接确认 Axiom 放置。

::: tip Axiom 预览不会同步给 WorldEdit
Axiom 中的位置和旋转只是客户端参考。WorldEdit 不会自动读取 Axiom 的预览状态，下一步必须加载服务器上的同名投影并重新确认位置。
:::

## 🔹 第二步：让 WorldEdit 加载投影

把投影文件交给管理员，由管理员放入服务器 WorldEdit 的 schematic 库。玩家不需要也不应该获取 SSH 权限。

在游戏内先查询可用文件：

```text
//schem list
```

加载目标文件时不写 `.schem` 扩展名：

```text
//schem load jmusouthgate
```

`//schem load` 只把文件加载到当前 WorldEdit 剪贴板，不会修改世界。

如果文件较大，建议使用简短且固定的英文文件名，例如：

```text
jmusouthgate-v1.schem
jmubuilding-v1.schem
```

## 🔹 第三步：无方块试放

站到预定起点，面向最终建筑朝向，然后执行：

```text
//paste -n
```

`-n` 表示不放置任何方块，只选择即将粘贴的区域。此时用 WorldEditCUI 的线框检查范围、方向和高度。

需要调整方向时，在正式粘贴前执行：

```text
//rotate 90
//flip
```

每次调整后重新执行 `//paste -n` 检查线框。确认范围完全正确后再进入下一步。

## 🔹 第四步：正式粘贴

确认无方块试放结果无误后执行：

```text
//paste -a
```

`-a` 表示跳过投影中的空气方块，只写入实际方块。这能减少不必要的方块更新，也能降低投影空白区域覆盖现有建筑的风险。

粘贴完成后立即检查：

- 建筑边缘和入口是否对齐；
- 地基是否与地形衔接；
- 高度是否符合预期；
- 远处区块是否完整加载；
- 是否误覆盖道路、像素画或其他建筑。

## 🔹 第五步：撤回错误操作

如果位置、方向或范围不对，立即执行：

```text
//undo
```

如果撤销过多，可执行：

```text
//redo
```

不要在未撤销上一次错误粘贴的情况下连续重复 `//paste`。连续粘贴会扩大影响范围，也会让后续定位和回滚更困难。

::: warning 不要随意使用 `-o`
WorldEdit 的 `-o` 表示“粘贴回原坐标”，不是普通的“在原位预览”。常规施工应使用 `//paste -n` 试放、`//paste -a` 正式放置。
:::

## 🔹 两个投影的参考示例

### 南门 `jmusouthgate.schem`

适合先用南门投影完整走一遍流程：

```text
//schem load jmusouthgate
//paste -n
//paste -a
```

确认线框位置、朝向和高度都没有问题后再正式放置。

### 建筑 `jmubuilding.schem`

建筑体量更大，正式粘贴前应额外确认：

- 目标范围的区块已加载；
- 周围没有正在施工的其他建筑师；
- 服务器近期备份可用；
- 先执行 `//paste -n` 检查完整占地；
- 出现缺块时先 `//undo`，不要直接重复粘贴。

## 🔹 常见问题

| 问题 | 处理 |
| --- | --- |
| `//schem list` 看不到文件 | 联系管理员确认文件已上传，并检查大小写和文件名 |
| `//schem load` 失败 | 确认文件是 Sponge Schematic v3，命令中不要写 `.schem` |
| Axiom 能预览，但 WorldEdit 没反应 | Axiom 预览不会同步给 WorldEdit，需要单独加载服务端文件 |
| `//paste -n` 的线框位置不对 | 调整站位和朝向，或先 `//rotate` / `//flip` |
| 正式粘贴后部分区域缺失 | 先 `//undo`，加载目标区块后重新试放和粘贴 |
| WorldEditCUI 没有线框 | 检查 WorldEditCUI 是否加载，并确认整合包版本正确 |

## 🔹 施工安全

- 第一次使用投影时先在低风险区域测试；
- 建筑底部从 `Y=6` 开始，不要覆盖 `Y=5` 的像素地图；
- 大范围操作前联系管理员和其他在线建筑师；
- 先试放、再正式粘贴、出错立即撤销；
- 施工结束后在聊天中说明完成的区域。
