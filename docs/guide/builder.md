# 建筑权限与协作规范

## 🔹 权限模型

服务器把“参观”和“建筑”分开管理。

| 身份 | 默认模式 | 建造权限 | Axiom / WorldEdit |
| --- | --- | --- | --- |
| 普通访客 | 创造模式、可飞行 | 禁止 | 禁止 |
| 建筑师 | 创造模式、可飞行 | 允许 | 允许 |
| OP | 创造模式、可飞行 | 允许 | 允许 |

所有玩家进入后都拥有 `everyone` 角色。建筑师还会获得 `builder` 角色。当前服务器管理员为 `VincentZyu` 和 `BoWuYinGuo`，两人同时拥有 OP 与建筑师权限。

::: warning 参观不等于编辑
普通访客虽然使用创造模式，但服务端的世界保护规则会阻止破坏、放置、交互、攻击、TNT、火焰、流体和物品丢弃等行为。
:::

## 🔹 如何申请建筑师

请向服务器管理员说明：

1. Minecraft ID；
2. 计划参与的建筑或校园区域；
3. 过往建筑作品或参考图；
4. 是否熟悉 Axiom / WorldEdit；
5. 预计施工范围和时间。

管理员审核后会执行角色分配。不要借用他人的账号或冒用 ID。

## 🔹 建筑前检查

- 确认自己已经获得 `builder` 角色；
- 先用小范围测试选区、替换和撤销；
- 大范围操作前通知其他在线建筑师；
- 不要在卫星像素地图 `Y=5` 区域随意施工；
- 避免一次执行超大范围 `//replace`、`//set`、`//paste`；
- 施工结束后在聊天中说明完成了哪个区域。

## 🔹 Axiom 基础操作

整合包已内置 Axiom。默认按键：

| 功能 | 按键 |
| --- | --- |
| 框选 | `B` |
| 魔法选择 | `M` |
| 自由手绘 | `G` |
| 快速填充 | `Ctrl+F` |
| 快速替换 | `Ctrl+R` |
| 复制 | `Ctrl+C` |
| 粘贴 | `Ctrl+V` |
| 删除选区 | `Delete` |
| 撤销 | `Ctrl+Z` |
| 重做 | `Ctrl+Y` |

Axiom 的权限按 `axiom.*` 分配给 `builder`。如果界面能打开但所有编辑操作失效，通常是角色未生效；重新登录后再确认。

## 🔹 WorldEdit 基础命令

服务端已安装 WorldEdit，可通过聊天栏执行：

```text
//wand
//pos1
//pos2
//copy
//paste
//rotate 90
//flip
//undo
//redo
//set stone
//replace dirt grass_block
//sphere glass 8
//cyl quartz_block 5 12
```

常用查询：

```text
//sel
//size
//count stone
//distr
```

### 粘贴建议

- 使用 `//paste -a` 跳过空气，减少不必要的方块更新；
- 大体量粘贴前先加载目标区块；
- 失败时先执行 `//undo`，不要连续重复粘贴；
- 需要大面积改造时先联系服务器管理员。

## 🔹 校园像素地图

服务器主世界已铺设一幅 `4096 × 4332` 的卫星图像素地图，像素材质位于 `Y=5`。

- 建筑请建在地图上方；
- 不要在未经批准时替换像素画；
- 大范围透明粘贴要注意空气层，避免覆盖现有建筑；
- 新建区域建议先使用 `/spawn` 或 Xaero 地图定位，再开始施工。

## 🔹 协作红线

以下行为会被记录并可能直接撤销权限：

- 冒用他人 ID；
- 未经授权清除他人建筑；
- 恶意 TNT、火焰、流体或实体攻击；
- 使用脚本持续刷屏或批量破坏；
- 把服务器登录密码或管理命令泄露给访客；
- 对整幅像素画执行未备份的批量替换。

发生误操作时立即停止，并联系管理员使用 Ledger 回滚和备份恢复。
